# Zihao Guo · Interactive Project Demos

Interactive demos of two independently designed research tools, hosted on GitHub Pages.

**[Explore the demos](https://zanquer.github.io/zihao-project-demos/)**

- **[ScoreTrace](https://zanquer.github.io/zihao-project-demos/scoretrace/)** — A semiconductor research dashboard covering 15 A-share and 15 US stocks. Supports market switching, search, sub-industry filtering, sorting, score breakdowns, valuation context, and source evidence.
- **[Global Events Dashboard](https://zanquer.github.io/zihao-project-demos/global-events/)** — A research workspace with five modules: macroeconomic calendar, global indices, rates and commodities, news, and technology companies. Supports date and region filters, charts, event details, and company watchlists.

The demos use data snapshots captured on **2026-10-03**, preserving source timestamps and missing values. They do not fetch real-time market data; reloading reads the same snapshots. This repository contains the built static demos and their data files.

## 中文说明

这是 Zihao Guo 独立设计的两个研究工具的交互展示版，通过 GitHub Pages 公开访问。

**[项目展示入口](https://zanquer.github.io/zihao-project-demos/)**

- **[ScoreTrace](https://zanquer.github.io/zihao-project-demos/scoretrace/)**：覆盖 15 只 A 股及 15 只美股的半导体研究观察池，支持市场切换、搜索、子行业筛选、排序、评分拆解、估值解读及原始证据查看。
- **[全球事件台](https://zanquer.github.io/zihao-project-demos/global-events/)**：包含宏观日历、全球指数、利率与大宗商品、新闻、科技公司五个研究模块，支持日期与地区筛选、图表、事件详情及公司关注。

展示版使用 **2026-10-03** 采集的数据快照，保留来源时间与缺失值。不会获取实时行情，重新加载仍读取相同快照。仓库保存已构建的静态演示页面及其数据文件。
